│                             │
│ Recommendations:            │
│ • Open register #3          │
│ • Call backup cashier       │
└─────────────────────────────┘
```

**2. Table Intelligence**
```
Vision AI détecte automatiquement:
- Table occupée vs libre
- Dirty table (assiettes visibles)
- Customer ready to pay (looking around, checking time)

Benefits:
- Hostess voit status réel en temps réel
